# 比较方案再定设计

先问：若新需求从一开始就存在，核心数据和边界会怎样设计？对照当前实现，找出真正不适用的假设和最小迁移范围；已有契约能自然表达的变化直接实现。

确有关键分歧时，选择能区分候选方案的输入与故障条件，用最小原型比较正确性、操作成本和失败恢复。能由现有证据排除的方案无需另做原型。记录决定选择的观察，再按 [小步验证](../principle-small-steps/SKILL.md) 推进；协议取舍写回负责该契约的设计正文。
