# 诊断与验证

| 触发条件 | 读取原则 |
| --- | --- |
| 有错误需要定位，或连续修复仍然失败 | [修复根因](../../mini-sla-fix-root-causes/SKILL.md) |
| 新增、修改或评审测试与守卫 | [验证行为](../../mini-sla-test-behavior/SKILL.md) |
| 准备依据延迟、吞吐、成本、分数或成功率作判断 | [解释测量结果](../../mini-sla-explain-measurements/SKILL.md) |

“测试通过”与“用户问题已解决”分别取证。重复写入或迟到结果造成的失败，同时进入 [模型与边界](models-and-boundaries.md) 定位相关协议。
