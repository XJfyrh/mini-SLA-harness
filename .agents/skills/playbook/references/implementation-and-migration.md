# 实现与迁移

| 触发条件 | 读取原则 |
| --- | --- |
| 准备增加层、参数、适配器或与现有逻辑重复的分支 | [先减后加](../../principle-subtract-first/SKILL.md) |
| 多步实现、跨模块修改或分阶段交付 | [小步验证](../../principle-small-steps/SKILL.md) |
| 已决定替换内部接口，需要处理原有调用方和兼容路径 | [迁移调用方再删除旧接口](../../principle-migrate-callers/SKILL.md) |
| 重复手工操作、批量变换，或需要让他人复跑一项复杂验证 | [把重复工作做成工具](../../principle-build-tools/SKILL.md) |

先完成一个有观察结果的单位，再扩展依赖它的工作。是否抽象、删除或编写工具，由当前重复和契约决定。
