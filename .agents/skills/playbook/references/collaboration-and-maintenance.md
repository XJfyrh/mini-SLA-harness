# 协作与维护

| 触发条件 | 读取原则或技能 |
| --- | --- |
| 实施中需要常规选择、等待信息或遇到局部阻碍 | [主动推进可逆工作](../../principle-advance-work/SKILL.md) |
| 大文件、海量日志、反复读取或跨轮次继续任务 | [保留关键上下文](../../principle-context-discipline/SKILL.md) |
| 代码难追踪、隐式状态多，或文档难以指导操作 | [降低阅读成本](../../principle-reader-first/SKILL.md) |
| 同一问题反复被纠正，或维护仓库规则与技能 | [把规则变成检查](../../principle-encode-invariants/SKILL.md) |
| 长时间自主执行、多阶段改造、交接，或用户要求展示过程 | [展示工作依据](../../show-me-your-work/SKILL.md) |

一次维护优先修订已有规则；新原则应有不同的触发条件和决策。说明具体行为、结果与未知点，让下一位执行者能继续工作。
