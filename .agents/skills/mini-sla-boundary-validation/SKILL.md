# 在边界建立信任

CLI、配置、provider 响应与数据库记录进入业务逻辑时，把原始值解析成领域数据，检查形状和语义，给出可定位错误。边界负责转换与错误呈现，领域逻辑负责决策；内部重复解析相同的不可变事实应合并。

区分“输入已合法”和“现在仍允许操作”。预算、代次、租约、对象归属和生命周期会变化，必须在实际提交的事务或授权边界重新判断；内存类型和较早的读取不能代替这一步。落实方式遵循 [事务协议](../../../docs/design/03-state-transactions.md)。
