# 让重复执行收敛

为同一逻辑操作确定稳定身份、冲突语义和提交边界。每次依据实际持久状态判断还缺什么；重复请求返回一致结果，内容冲突显式失败。检查提交前后被中断及连续恢复时，已完成的结果是否被重复接受、遗漏或覆盖。

本地结果接受幂等不代表远端只执行或收费一次。发送后结果未知时保留调用身份与待对账状态；不能靠换请求键、清空预留或自动重发制造成功。费用和恢复规则直接遵循 [状态协议](../../../docs/design/03-state-transactions.md)，故障验证对照 [验收用例](../../../docs/design/04-implementation-validation.md)。
