# 把重复工作做成工具

先用一个实际样本确认转换规则或验证方法，再判断现有命令能否完成。重复执行成本或独立复核价值足够时，把步骤做成最小脚本，明确输入、输出、退出码和重复执行语义；简单局部编辑直接完成。

对批量修改先预览差异，用样本结果校准工具，再逐批验证。长期有用的工具接入现有开发入口；单次分析产物放在忽略目录。脚本成功退出后仍要读取实际结果，错误不能被空输出或默认成功掩盖。
