# 用模型表达规则

先列出实体身份、允许状态、主要读写路径和唯一写入者，再选择数据结构。互斥状态用明确变体表达；可推导的值不再保存一份需要同步的副本。重复条件优先收敛为同一模型或状态转换。

类型要阻止当前确实会混淆的值和非法组合。解析后逐步收窄类型，新增变体检查所有分支；不靠宽泛的 `Any`、`cast` 或忽略类型错误掩盖缺失校验。Python 类型声明不执行运行时校验，持久化约束仍落实到 [边界和事务](../mini-sla-boundary-validation/SKILL.md)。

结构应减少重复规则、无效状态或所有权歧义；若只增加跳转层，保留清楚的局部实现。协议字段以 [状态协议](../../../docs/design/03-state-transactions.md) 为准。
