# 取得真实反馈

先明确要判断的事实，再选择能直接观察它的执行路径。运行真实入口，读取实际输出和副作用：写库后重开读取，安装后执行 CLI，性能变化保留原始样本及环境身份。

fake 用于稳定触发协议和故障边界；外部契约、运行环境与效果由对应的真实探针验证。探针条件未满足时记录缺少的条件，在已有授权范围内准备可执行的验证。

结论绑定本次代码、输入和运行结果。检查证据中的源码身份、退出码与日志；未运行、失败和未知各自说明。源码变化后重跑受影响验证，不能沿用旧的成功结论。
