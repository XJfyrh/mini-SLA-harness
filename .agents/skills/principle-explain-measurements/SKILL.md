# 解释测量结果

先确认数字测到了目标工作：输入与环境一致、正确性通过，计时包含约定阶段，没有漏跑、缓存替代或只挑成功样本。报告分母、运行次数、样本分布和失败；费用保留所有真实调用及未知项。

性能变化用运行时 profile、计数器或对照实验定位限制因素，检验测量器本身和噪声能否解释差异。尚无证据定位的原因标为待验证假设，并设计能区分原因的下一次测量，不把代码阅读推测写成瓶颈结论。

先校准测量方法，再依据结果作判断。把结论连接到原始样本、配置和代码身份；基线与改动后的测量使用一致口径，需要独立审计时另存审计证据。
