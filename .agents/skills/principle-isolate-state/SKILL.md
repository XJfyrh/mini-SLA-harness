# 先隔离共享状态

先列出各执行者会修改的路径、键、分支和对象，判断是否必须共享同一份可变状态。独立尝试使用自己的工作目录和产物，读取或汇总时再组合；并行开发使用各自工作树，合并前检查接口契约。

必须共同维护的权威事实集中到受控写入边界，以事务、排他所有权和 fencing 处理竞争及迟到写入。不能把应原子更新的账本拆成相互矛盾的副本。用真实并发和迟到提交验证互斥及拒绝行为。
