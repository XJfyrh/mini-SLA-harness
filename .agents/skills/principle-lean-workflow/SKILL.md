# 敏捷轻量

用能完整解决当前问题的最小改动，尽快取得真实反馈。按影响范围、失败后果和已有证据选择阅读、记录、审查与验证；必要行为、失败处理和契约仍要覆盖。

新增机制应解决具体的重复成本或已识别风险，理由写在现有任务说明或提交中即可。先复用已有入口与证据；同一会话已读且未变化的内容直接复用。

达到依据需求确定的验收条件即交付；执行中发现遗漏则补齐，额外改进留给后续任务。维护相关流程时合并重复规则、删除失效步骤。按 [小步验证](../principle-small-steps/SKILL.md) 划分交付，按 [先减后加](../principle-subtract-first/SKILL.md) 简化实现。
