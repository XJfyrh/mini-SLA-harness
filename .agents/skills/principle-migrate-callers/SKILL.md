# 迁移调用方再删除旧接口

先盘点调用、导出、CLI 配置、测试、示例和持久化格式，区分受控内部调用方与已发布契约。内部接口按完整行为迁移调用方，删除旧实现及只固定旧内部形状的测试，验证实际入口。

跨步骤迁移先写清目标和可验证边界，保留当前改动的高信号检查，在交付前恢复完整验证。兼容层必须对应具体使用者及退出条件；涉及外部调用方或已有数据时，按真实兼容需求安排过渡与迁移，不能用“内部重构”跳过它们。
